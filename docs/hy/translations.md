# Թարգմանություններ. անվանումներ հայերեն, անգլերեն և ռուսերեն

[English](../en/translations.md) | **Հայերեն** | [Русский](../ru/translations.md)

Կայքը անվանումները հրապարակում է միայն հայերեն։ Տվյալների բազայում յուրաքանչյուր անվանում կա երեք լեզվով.

| ինչ | հայերեն | անգլերեն / ռուսերեն | որտեղ |
|---|---|---|---|
| դասակարգիչներ (գործառական, ծրագրեր, գերատեսչություններ, տնտեսագիտական հոդվածներ, եկամուտների բաժիններ, խմբեր, հաշիվներ) | `name_hy` ձևերից | `name_en`, `name_ru` բառարաններից | `dim_*` |
| դեֆիցիտի տողեր | `label_hy` | `label_en`, `label_ru` | `fact_deficit` |
| կայքի ինտերֆեյս (վերնագրեր, տարբերակներ) | `hy` | `en`, `ru` | `meta_label` |
| հաշվետվությունների անվանումներ, ժամանակաշրջաններ, եկամուտների տեսակներ, տնտեսագիտական դասակարգման վերին մակարդակներ | — | — | `src/arm_budget/reference.py` |
| պայմանագրերի գործընկերներ | `partner_hy` | `partner_en`, `partner_ru` — **տառադարձություն**, ոչ թե թարգմանություն | `fact_contract` |

## Բառարաններ

`data/translations/<context>.csv` (տարբերակվում են git-ում), սյունակներ՝ `hy,en,ru`.

| ֆայլ | անվանումներ |
|---|---|
| `functional.csv` | գործառական դասակարգում (բաժիններ, խմբեր, դասեր) |
| `program.csv` | ծրագրեր / միջոցառումներ |
| `department.csv` | գերատեսչություններ (պետական մարմիններ) |
| `economic.csv` | տնտեսագիտական հոդվածներ |
| `revenue.csv` | եկամուտների բաժիններ, խմբեր և գանձապետական հաշիվներ |
| `deficit.csv` | դեֆիցիտի հաշվետվության տողեր |
| `labels.csv` | կայքի ինտերֆեյս |

Build-ը անվանումը փնտրում է իր համատեքստի բառարանում՝ ըստ հայերեն տեքստի (հետո՝ ցանկացած բառարանում), համեմատելով միայն
տառերն ու թվերը — կետադրության, բացատների և տառաչափի տարբերությունները նշանակություն չունեն։ Բոլոր բառարանները
բեռնվում են `dim_translation`-ում։

Տերմինները և ոճը ամրագրված են [GLOSSARY.md](../../data/translations/GLOSSARY.md)-ում. COFOG-ի անվանումները
գործառական դասակարգման համար, «ՀՀ» = "RA" / «РА», «միջոցառում» = "measure" / «мероприятие», նախադասության
սկզբում միայն մեծատառ և այլն։

## Ինչպես են կատարվել թարգմանությունները

Բառարանների առաջին տարբերակը (≈2 300 անվանում 2024–2026 թվականների համար) ստեղծվել է մեծ լեզվական մոդելով (Claude)
խմբաքանակներով՝ բառարանին համապատասխան, և ստուգվել է ավտոմատ (յուրաքանչյուր հայերեն անվանում մնացել է անփոփոխ,
երկու թարգմանություններն էլ առկա են)։ Այն հապավումները, որոնց վերծանումը հստակ չէ, թողնվել կամ տառադարձվել են։
Հայերեն տեքստը մնում է հիմնականը (authoritative). թարգմանությունները նախատեսված են որոնման և ընթերցանության համար, ոչ
որպես պաշտոնական անվանումներ։ Ուղղումները ողջունելի են՝ խմբագրեք CSV-ն և վերակառուցեք։

Պայմանագրերի գործընկերները (≈ ընկերություններ և ֆիզիկական անձինք) տառադարձվում են ավտոմատ
(`src/arm_budget/translit.py`)՝ լատինատառը՝ հայկական անձնագրային / BGN-PCGN ընդհանուր պրակտիկայով, կիրիլիցան՝
սովորական ռուսական արտահայտմամբ. իրավական ձևերը թարգմանվում են (ՓԲԸ → CJSC / ЗАО, ՍՊԸ → LLC / ООО, ԱՁ → IE / ИП, …),
իսկ գծիկները, որոնք կայքն օգտագործում է չակերտների փոխարեն, կրկին վերածվում են չակերտների։

## Նոր անվանումներ

Երբ կայքում նոր տարի է հայտնվում, նրա հետ հայտնվում են նոր ծրագրեր, հաշիվներ և տողեր։ Առանց թարգմանության
անվանումները թվարկվում են `qc_missing_translation`-ում (և `qc_summary`-ի `missing_translation` ստուգումը դառնում է
`warn`).

```bash
make build
python -m arm_budget translations           # -> data/translations/pending/<context>-NNN.csv (hy filled, en/ru empty)
# fill the en and ru columns: by hand, or with a machine translation following GLOSSARY.md, then review
python -m arm_budget translations --merge   # merges the filled rows into data/translations/<context>.csv
make build docs
```

`pending/`-ի ֆայլերը չեն տարբերակվում. ֆայլը հեռացվում է նրա բոլոր տողերը միավորելուց հետո։
