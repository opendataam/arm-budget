# Переводы: названия на армянском, английском и русском языках

[English](../en/translations.md) | [Հայերեն](../hy/translations.md) | **Русский**

Сайт публикует названия только на армянском языке. В базе данных каждое название есть на трех языках:

| что | армянский | английский / русский | где |
|---|---|---|---|
| классификаторы (функциональный, программы, ведомства, статьи экономической классификации, разделы, группы и счета доходов) | `name_hy` из форм | `name_en`, `name_ru` из словарей | `dim_*` |
| строки дефицита | `label_hy` | `label_en`, `label_ru` | `fact_deficit` |
| интерфейс сайта (заголовки, параметры) | `hy` | `en`, `ru` | `meta_label` |
| названия отчетов, периоды, виды доходов, верхние уровни экономической классификации | — | — | `src/arm_budget/reference.py` |
| контрагенты контрактов | `partner_hy` | `partner_en`, `partner_ru` — **транслитерация**, а не перевод | `fact_contract` |

## Словари

`data/translations/<context>.csv` (версионируются в git), столбцы `hy,en,ru`:

| файл | названия |
|---|---|
| `functional.csv` | функциональная классификация (разделы, группы, классы) |
| `program.csv` | программы / мероприятия |
| `department.csv` | ведомства (государственные органы) |
| `economic.csv` | статьи экономической классификации |
| `revenue.csv` | разделы, группы и казначейские счета доходов |
| `deficit.csv` | строки отчета о дефиците |
| `labels.csv` | интерфейс сайта |

При сборке название ищется по его армянскому тексту в словаре своего контекста (затем в любом словаре), при этом
сравниваются только буквы и цифры — различия в знаках препинания, пробелах и регистре не учитываются. Все словари
загружаются в `dim_translation`.

Термины и стиль зафиксированы в [GLOSSARY.md](../../data/translations/GLOSSARY.md): названия COFOG для
функциональной классификации, «ՀՀ» = "RA" / «РА», «միջոցառում» = "measure" / «мероприятие», регистр предложения и т. д.

## Как были сделаны переводы

Первая версия словарей (≈2 300 названий за 2024–2026 годы) была подготовлена большой языковой моделью (Claude)
пакетами в соответствии с глоссарием и проверена автоматически (каждое армянское название сохранено без
изменений, оба перевода присутствуют). Аббревиатуры, расшифровка которых неочевидна, сохранялись или
транслитерировались. Армянский текст остается авторитетным: переводы предназначены для поиска и чтения, а не как
официальные названия. Исправления приветствуются — отредактируйте CSV и пересоберите базу.

Контрагенты контрактов (≈ компании и физические лица) транслитерируются автоматически
(`src/arm_budget/translit.py`): латиницей — по распространенной практике армянских паспортов / BGN-PCGN, кириллицей —
по привычной русской передаче; организационно-правовые формы переводятся (ՓԲԸ → CJSC / ЗАО, ՍՊԸ → LLC / ООО,
ԱՁ → IE / ИП, …), а тире, которые сайт использует вместо кавычек, возвращаются к кавычкам.

## Новые названия

Когда на сайте появляется новый год, вместе с ним появляются новые программы, счета и строки. Названия без перевода
перечислены в `qc_missing_translation` (а проверка `missing_translation` в `qc_summary` получает статус `warn`):

```bash
make build
python -m arm_budget translations           # -> data/translations/pending/<context>-NNN.csv (hy filled, en/ru empty)
# fill the en and ru columns: by hand, or with a machine translation following GLOSSARY.md, then review
python -m arm_budget translations --merge   # merges the filled rows into data/translations/<context>.csv
make build docs
```

Файлы в `pending/` не версионируются; файл удаляется после того, как все его строки слиты.
