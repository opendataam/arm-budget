
## Проверки

| проверка | таблица | что проверяется |
|---|---|---|
| `unresolved_code` | `qc_unresolved_code` | у каждой строки дерева расходов и деревьев доходов (виды 1–3) есть код классификатора |
| `tree_total` | `qc_tree_total` | листья каждого дерева в сумме дают общий итог, опубликованный на сайте (годовой план и исполнение) |
| `tree_subtotal` | `qc_tree_subtotal` | каждый промежуточный итог, опубликованный на сайте, равен сумме своих дочерних строк |
| `revenue_types` | `qc_revenue_types` | налоги и пошлины + официальные трансферты + прочие доходы = все доходы (`SITE_EBUDG` 1+2+3 против 0) |
| `site_total` | `qc_site_total` | итоги в меню стартовой страницы = годовые планы последнего года в базе данных |
| `balance` | `qc_balance` | план расходов − план доходов = плановый дефицит, для каждого года |
| `contract_link` | `qc_contract_link` | у каждой строки расходов с контрактами есть данные о контрактах, и каждая страница контракта относится к какой-либо строке |
| `contract_paid` | `qc_contract_paid` | (справочно) строки, в которых платежи по контрактам превышают исполненную сумму строки |
| `missing_translation` | `qc_missing_translation` | у каждого армянского названия есть перевод на английский и русский |
| `renamed_code` | `qc_renamed_code` | (справочно) коды, название которых различается по годам |

## Особенности и проблемы источника

1. **В результатах только названия, без кодов.** Коды берутся из списков с флажками в формах; ≈5 % строк
   требуют пробного запроса (запроса с фильтром), потому что одно название соответствует нескольким кодам или отличается от списка
   (см. [sources.md](sources.md#коды-классификаторов-зачем-нужны-пробные-запросы)).
2. **Коды без названия в списках.** Списки классификаторов за год содержат несколько кодов с пустым названием
   (программы `004077`, `004576`, `004617`, группа доходов `1688`, несколько счетов доходов), хотя в результатах отображаются
   их названия (например, программа «Ուսուցչի օրվա առթիվ … պարգևատրում», группа доходов от государственных пошлин за
   торговлю алмазами). Пробные запросы проверяют эти коды в первую очередь; таблицы `dim_*` берут название из сетки результатов.
3. **Планы доходов при выборе «все доходы».** При `SITE_EBUDG = 0` сайт показывает планы только для общего итога;
   детализированные планы публикуются только по видам доходов, поэтому факты строятся из видов 1–3.
4. **Планы доходов устанавливаются на вид в целом.** ≈97 % годового плана налогов и пошлин и 100 %
   плана официальных трансфертов не распределены по разделам, группам или счетам (прочие доходы распределены полностью).
   При сборке эта часть сохраняется как одна строка на год и вид с `line_kind = 'unallocated'`
   (`qc_revenue_unallocated`); поэтому у многих счетов есть исполнение без плана. Сравнивайте план и исполнение
   доходов на уровне вида.
5. **Пунктуация и орфография.** Сетка отбрасывает запятые, точки с запятой и кавычки; списки их сохраняют, но содержат
   переносы строк (`\n` внутри слов), латинские буквы-двойники (`u` вместо `ս`) и отдельные опечатки. Названия в
   базе данных очищены от переносов строк; исходное написание сохранено.
6. **Названия меняются по годам** (переименованные министерства, переформулированные программы), а коды используются повторно для переименованных
   органов; `dim_*` хранят последнее название, `dim_name` — все названия по годам (`qc_renamed_code`). Переименованный орган может
   также получить новый код (например, Министерство экономики `104004` и `104007`).
7. **Живые данные.** Текущий год обновляется ежедневно; запросы, сделанные с разницей в несколько минут, могут немного отличаться. Страницы
   контрактов загружаются после запросов отчетов, поэтому их платежи могут быть немного свежее, чем
   `fact_expenditure`.
8. **Отчет о дефиците не аддитивен.** Детальные строки — это разбивка нумерованной строки над ними
   (органы, компании, займы) и могут пересекаться; некоторые подписи содержат остатки прошлых лет
   («ՀՀ 2017 թվականի պետական բյուջեի տարեսկզբի ազատ մնացորդ» в отчетах за 2024–2026 годы).
9. **Округление.** Суммы расходов и доходов имеют 4 знака после запятой (тысячи драмов), суммы дефицита и выгрузки Excel —
   2 знака; столбцы `%` на сайте округлены до целых.
10. **Только три года.** При добавлении нового года сайт удаляет самый старый; более старые данные есть только в
    релизах этого репозитория.
11. **Нестабильность сервера.** Сайт иногда сбрасывает соединения или не отвечает на запрос вовсе; сборщик
    повторяет попытки (см. [maintenance.md](maintenance.md)).
